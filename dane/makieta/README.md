# Udawane dane do makiety (`/makieta/`)

Wygenerowane skryptem [`generuj.mjs`](./generuj.mjs) (deterministyczny): 6 spraw z paczki pokazowej (`W052, W006, W023, W020, W027, W038`, spec §4) ze sztucznego zbioru `dane/zbior/testowy/` oraz 5 ogólników do testu A1. Rekomendacje, przesłanki, braki i „podobne sprawy” to **faktyczny wynik `app/logika`** (nie wpisane ręcznie); wzorzec z `dane/zbior/etykiety.csv`. Wszystkie osoby i numery są wymyślone.

Pliki: `makieta-dane.json` (dane), `../../makieta/dane.js` (to samo dla strony). Uruchomienie: `node dane/makieta/generuj.mjs`.
